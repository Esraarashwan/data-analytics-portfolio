# Data Analytics Portfolio

**Esraa Rashwan — Marketing Data Analyst**

Four end-to-end analytics projects spanning healthcare, retail, and marketing. Each project includes the source data, the analysis, an interactive dashboard, and a written report with quantified recommendations.

## 📊 Healthcare Revenue Cycle Management
A six-page Power BI dashboard analyzing the claim lifecycle for a healthcare provider — from billing through denial, appeal, and final resolution. Surfaces $9.65M in denied bills, a 42.30% bad debt rate, and identifies 57.53% of denials as avoidable.

**Tools:** Power BI · DAX · Power Query
[View project →](./revenue-cycle-management)

---

## 🚲 Sales & Customer Insights — Phantom Bikes
A two-page dashboard dissecting two years of bike sales. Sales grew 0.2% year-over-year but profit fell 34.6% — the analysis identifies discount-driven margin erosion as the root cause and recommends a pricing audit.

**Tools:** Power BI · Advanced DAX · RFM segmentation · Market basket analysis
[View project →](./sales-customer-insights)

---

## 📣 Marketing & E-commerce Performance
A three-page dashboard connecting ad spend to orders and customers across Facebook, Google, and Instagram. Flags a −21% overall ROI, identifies the top-performing campaign (152% ROI), and profiles customer cohorts and geographic demand.

**Tools:** Power BI · DAX · Power Query
[View project →](./marketing-ecommerce-performance)

---

## 🎯 Facebook Ad Campaign Performance
End-to-end analysis of 936 Facebook ads ($58.7K spend, 212M impressions). Finds a 4.3× CPA gap between best and worst audience segments, identifies $14.7K in wasted spend, and models budget reallocation scenarios with quantified impact — cutting CPA by up to 20%.

**Tools:** Excel · Power BI · SQL · Chi-square testing · Scenario modeling
[View project →](./fb-campaigns-analysis)
